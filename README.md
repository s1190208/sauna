- `index.html`：ランキングHP。検索、Tierとコメントの編集、施設別の公式サイトリンク、HTML/JSONの書き出し。
- `data/saunas.json`：全82施設のデータと施設の確認結果。

## 画像について（2026-10-10更新）
- **82/82施設**について、実際の施設写真の外部画像URLを登録済みです。生成画像は使っていません。
- `photoSource`（元ページ）・`photoCredit`（出典）・`photoSubject`（写っている設備）・`photoType`（掲載元の区分）・`photoUsageStatus`（利用条件）を各施設で保持しています。
- **写真データはこのリポジトリには保存していません**。掲載元サイト上の画像URLをブラウザが直接読み込みます。サイト側のホットリンク制限・画像削除・アクセス許可の影響を受け、表示できない施設がある可能性があります。画像が取得できないときは代替表示を出します。
- **写真の転載・二次利用・外部埋め込みの許諾は未確認です**。文化庁の説明では「拾い画」が自由に使えるわけではないため、一般公開での継続利用時は権利者の利用規約・許諾を確認してください：https://www.bunka.go.jp/seisaku/chosakuken/taisetsu/point/index.html
- 元画像・公式ホームページへのリンクを維持し、施設・取材媒体等のクレジットを各カードに表示します。写真の出典情報は利用許諾の代わりにはなりません。
- 現時点では**82件の参照URL登録完了**であり、全件のブラウザ表示成功と掲載許諾取得が完了したという意味ではありません。

## 画像URLの到達性テスト（2026-10-10）
- GitHub Actions の **Check sauna photo links** で82枚すべてのURLを検査しました。
- **77枚**はHEADリクエストで `200 + image/*` 応答を確認。
- **5枚**はHEAD結果だけでは判定できませんでしたが、Range GETの画像バイト署名（JPEG/WebPなど）と `206` 応答で実画像を確認。
- 北欧は以前の楽天トラベル画像URLが `404` のため、2026年の北欧とのコラボレーションに関するPR TIMESの記事に掲載されたサウナ室の画像へ差し替え、`200 + image/*` の応答を確認しました。
- 現在、**GitHub ActionsからのHTTP到達性検査では82/82件が成功**しています。**モバイルブラウザでの全件表示成功や転載許諾を意味するものではありません。**
- `.github/workflows/photo-audit.yml`：画像URLを更新すると自動で再検査し、`sauna-photo-audit` というJSON形式の成果物を保存します。手動でもGitHub Actionsの `workflow_dispatch` から実行できます。
- `tools/check-images.mjs`：画像ファイル全体をダウンロードせず、HEADと必要に応じて短いRange GETで応答を確認します。
- 公開HPにも **「写真の表示をチェック」** ボタンがあります。利用端末で現在表示中の施設画像を確認でき、表示失敗・タイムアウトのリストをコピーできます。スマートフォンのモバイル回線では通信量にご注意ください。
