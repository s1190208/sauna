# MY SAUNA ATLAS

本人が訪れたサウナ82施設の私的Tierランキングです。元のTier・掲載順・ユーザーコメントを保持しています。

## ファイル
- `index.html`：ランキングHP。検索、Tierとコメントの編集、施設別の公式サイトリンク、HTML/JSONの書き出し。
- `data/saunas.json`：全82施設のデータと施設の確認結果。

## 施設特定状況（2026-10-10）
- **81施設**：対象施設と公式サイトを特定（`verified`）。
- **1施設**：東京都立川市「松見湯」は対象施設を特定済みですが、店舗独自の公式サイトは未確認です。東京都浴場組合の施設案内を代替登録（`directory`）。
- **全82施設**に案内先URLを登録済み。組合ページと施設公式ページを区別して表示します。

## 画像について（2026-10-10更新）
- サイトに掲載設定した画像は **7施設**。実在する施設の写真で、**イメージ生成画像は使用していません**。
- 各画像に `photoSource` と `photoCredit` を登録し、画面にも画像掲載元へのリンクを表示します。
- 施設公式サイト掲載の写真4件、施設関連のプレスリリース・取材記事等に掲載された写真3件。
- サイトは画像元URLへの外部参照で表示します。**転載・二次利用の許諾が得られたという意味ではありません**。一般公開を継続する場合は利用規約や権利者の許可を確認してください。
- 画像の表示がブロックされた場合は「公式写真を読み込めませんでした」と表示します。
- 写真未登録75施設は空欄を維持しています。

## 名称について
- 元の名前は `originalName` で追跡し、確認した名称は `nameSource` と `nameReview` に公式サイトへの根拠を記録しています。
- 名称の表記ゆれ・支店名は調査しながら順次更新します。Tier、掲載順、ユーザーのコメントは変更しません。

## 技術面
- 静的HTMLで表示。GitHub Pages等でホスティング可能。
- ブラウザ内での編集はlocalStorageに保存され、GitHubへのコミットとは独立しています。
