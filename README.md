# MY SAUNA ATLAS

82施設の個人的なサウナTierランキングです。元のTier・施設順・12件のコメントを維持しています。

## ファイル
- `index.html`：ランキングHP本体。施設検索、Tier編集、公式サイトへのリンク、HTML/JSONエクスポート。
- `data/saunas.json`：全82施設の元データと公式サイト調査結果。

## 公式サイト調査（2026-10-10）
- **77施設**：該当施設の公式HP特定済み（`verified`）
- **3施設**：公式ブランド・グループサイトを仮登録。どの施設か確認待ち（`candidate`）
- **1施設**：店舗独自公式サイト未確認のため東京都浴場組合の施設案内を代替登録（`directory`）
- **1施設**：対象施設が複数あるためリンク未登録（`needs-confirmation`）

## 写真について
`photo` フィールドは、出典と利用条件を確認した画像を追加する場所です。現在の空欄は**写真未登録**です。公式サイトへのリンクは画像を無断転載して良いという許可ではありません。生成画像を実施設の写真と偽って掲載しないでください。

## 技術情報
- 静的HTML（追加のフレームワークは不要）、スマホ対応
- 表示編集データはブラウザのlocalStorageに保存。GitHub上のファイル更新とは別です
- 編集結果はHTML/JSON書き出しでバックアップ可能
- GitHub Pages等に公開する場合はプライバシーと著作権を確認してください
