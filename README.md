# MY SAUNA ATLAS

本人が訪れたサウナ82施設の私的Tierランキングです。元のTier・掲載順・ユーザーコメントを保持しています。

## ファイル
- `index.html`：ランキングHP。検索、Tierとコメントの編集、施設別の公式サイトリンク、HTML/JSONの書き出し。
- `data/saunas.json`：全82施設のデータと施設の確認結果。

## 画像について（2026-10-10更新）
- 掲載設定 **29/82施設**。**残り53施設は画像未登録**。画像生成は使用せず、実際の施設を撮影した写真を対象にしています。
- 公式施設サイト、実施設の取材記事、旅行情報サイトなどの写真を参照し、各画像に `photoSource`・`photoCredit`・`photoSubject`・`photoType` を記録しています。
- 画像は掲載元URLへの外部参照です。**著作権者からの転載許諾や、画像配信元からの外部埋め込み許可は未確認**です。公開するWebサイトで継続利用する場合は権利者の利用条件を確認してください。
- 写真がブロック・削除された場合は代替表示に切り替わります。実際のブラウザでの全画像ロード成功は検証できていません。

- **Tierや本人のコメントに変更は加えていません**。名称に表記ゆれが見つかった場合は施設に確認して修正してください。
